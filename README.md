# cpp-projects

This repository contains C++ practice programs prepared for AI 271 – Programming for AI.

## Files
- `hello_world.cpp` – A basic C++ program that prints `Hello, AI Course!`.

## How to compile and run
```bash
g++ hello_world.cpp -o hello_world
./hello_world
```
On Windows, run `hello_world.exe` after compilation.

## Expected output
```text
Hello, AI Course!
```
